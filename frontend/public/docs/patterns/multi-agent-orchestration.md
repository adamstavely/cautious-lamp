## Make the agents visible

When several agents work on one task, people need to know who is doing what.

- Give each agent a name and a one-line role ("Researcher: finds sources", "Writer: drafts the summary").
- Show a timeline or task list of which agent is working on which step, and what each has finished.
- Attribute every result to the agent that produced it, with its sources.

## Keep people in charge

- Let people approve the plan before agents start on anything costly or irreversible.
- Show hand-offs between agents, and let people stop, edit or redirect any step.
- Ask for confirmation before any agent acts outside the workspace (sending, publishing, changing data).
- Make it possible to rerun one step without starting the whole task again.

## When agents disagree or fail

- Show conflicting results side by side instead of silently picking one.
- If one agent fails, say which step failed and what the others still produced.
- Keep a log of what each agent did, for review and for audits.

## Accessibility

- Present agent activity as a structured list with headings, not only as a diagram.
- Announce step completions politely; don't flood screen readers with every intermediate message.
- Make it possible to pause updates while reading.
